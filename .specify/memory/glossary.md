# 📖 Glossário Ubíquo do Projeto (glossary.md)

| Termo | Definição no Contexto do Projeto |
| :--- | :--- |
| **Vavá / Valesca Almeida** | Artista titular do portal; atriz dramática, cômica e comediante stand-up, no ar na TV Globo e ativa na ponte aérea Goiânia ⇄ Rio de Janeiro. |
| **Olga** | Personagem interpretada por Valesca Almeida na novela musical *"Coração Acelerado"* da TV Globo / Globoplay (gerente da lanchonete contracenando com a protagonista Eduarda). |
| **Ponte Aérea GYN ⇄ RJ** | Disponibilidade e rotina de trabalho ativa entre Goiânia (GO) e Rio de Janeiro (RJ) para produções audiovisuais, teatrais e shows. |
| **Self-Tape** | Vídeo de teste de interpretação gravado pela atriz para envio a produtores e diretores de elenco. |
| **Stand-Up Comedy** | Formato de apresentação cômica autoral ao vivo com microfone; no portal, exemplificado pelo show no *Guardians Comedy Club*. |
| **Lordicon** | Biblioteca de ícones animados em formato JSON vetorial (Lottie), recoloridos dinamicamente pelo componente `AnimatedLordIcon.jsx`. |
| **TV Studio: Coral & Índigo** | Paleta cromática oficial do projeto baseada em tríade da Adobe Color (Fundo Escuro `#111122`, Coral Elétrico `#FF5E6C`, Âmbar `#FFBE0B`, Índigo `#4338CA`). |
| **Caddy** | Servidor web HTTP/2 e HTTP/3 em contêiner Docker que gerencia automaticamente a emissão e renovação de certificados SSL HTTPS via Let's Encrypt. |
| **Single Page Application (SPA)** | Aplicação web em página única onde a navegação ocorre via scroll suave e renderização reativa sem recarregar o documento. |
| **assetUrl** | Utilitário em `src/utils/assetUrl.js` que resolve dinamicamente os caminhos de mídias entre a raiz (`/` na VPS) e o subcaminho (`/vava/` no GitHub Pages). |
| **Spec-Driven Development (SDD)** | Metodologia onde toda funcionalidade é rigorosamente especificada (`spec.md`), planejada (`plan.md`) e decomposta em tarefas (`tasks.md`) antes da codificação. |
| **deploy.sh** | Script Bash em `/opt/vava/deploy.sh` que atualiza o código na VPS Hostinger, reconstrói o Docker e limpa imagens antigas em um único comando. |
